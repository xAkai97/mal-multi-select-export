# MAL Multi-Select Export - User Guide

## Overview
The MAL Multi-Select Export is a lightweight Chrome extension that makes it easy to bulk-select anime titles from MyAnimeList's seasonal anime pages and export them to your clipboard, JSON, or CSV.

## Features
- **Visual Overlay**: Injects selectable checkboxes over every anime card.
- **Batch Selection**: Use shift-click or right-click context menus to select ranges of anime.
- **Keyboard Shortcuts**: Use `Ctrl+A` to select all, `Escape` to clear, `Ctrl+Z` to undo, and `Ctrl+C` to copy.
- **Global Context Menu**: Right-click anywhere on the page to quickly invert selection, copy, or download.
- **Toggle Extension**: Easily disable the extension's overlay directly from the extension icon.

## How to Use
1. Visit [MyAnimeList Seasonal Anime](https://myanimelist.net/anime/season).
2. You will see a new toolbar at the top and checkboxes on each anime card.
3. Click the checkboxes to select anime, or use right-click on a checkbox to set start/end points for bulk selection.
4. Use the toolbar to Copy, or click "Download ▼" to save the list as JSON or CSV.

## Disabling the Overlay
If you want to temporarily disable the extension and browse MyAnimeList normally:
1. Locate the **MAL Multi-Select Export** icon in your browser's extension toolbar.
2. Right-click the extension icon.
3. Click **"Disable MAL Export Overlay"** (it functions as a toggle).
4. The toolbar and all checkboxes will instantly disappear from the page.
5. To re-enable it, simply right-click the icon again and uncheck the option.

## Settings
Click the "Settings" button in the toolbar to access:
- **Theme**: Choose between Auto (System), Light, and Dark mode for the extension's dialogs.
- **Context Menu Toggle**: If you find the right-click menu annoying, you can disable it here.
